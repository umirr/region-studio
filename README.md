# Region Studio Desktop 0.6.0

Windows용 오프라인 일러스트 영역 선택 및 재채색 앱입니다. 모델과 실행 환경이 포함되어 있으며 GPT 계정/API 키 및 인터넷 연결이 필요하지 않습니다.

## 설치와 작업

`Region-Studio-Setup-0.6.0.exe`를 실행하여 설치한 다음 바탕 화면의 Region Studio를 엽니다.

1. **폴더 열기**에서 PNG/JPG/WebP 이미지가 들어 있는 폴더를 선택합니다. 현재는 선택한 폴더 바로 아래 파일을 읽습니다.
2. 목록에서 이미지 선택 → **AI 분석** → 포함/제외 클릭으로 영역 지정 → 후보 또는 브러시로 보정합니다.
3. 색상과 불투명도를 설정합니다. **선택 범위 표시**를 끄면 실제 결과를 볼 수 있습니다.
4. **새 영역**으로 여러 레이어를 만듭니다. 작업은 자동 저장됩니다. 이전/다음 버튼이나 방향키로 이미지 사이를 이동합니다.
5. **작업 결과 일괄 저장**은 현재 폴더의 저장된 작업을 새 결과 폴더에 PNG로 내보냅니다.

원본 파일은 덮어쓰지 않습니다. 자동 저장은 Windows 사용자 앱 데이터의 `region-studio-desktop/projects` 폴더에 저장됩니다. 같은 원본 폴더를 다시 열면 복원됩니다. 원본 파일의 위치·이름·내용이 바뀌면 기존 작업과 연결되지 않을 수 있습니다. 앱을 삭제하기 전에 작업 결과와 학습 마스크를 내보내세요.

## 학습용 데이터 수집

정확하게 보정한 마스크를 확인하고 **현재 마스크 정답 확정**을 누릅니다. 변경하면 확정이 해제됩니다. **확정 마스크 내보내기**는 현재 폴더의 확정된 이미지에 대해 다음 파일을 만듭니다.

- 원본 이미지
- 영역별 흑백 PNG 마스크(흰색이 선택 영역)
- 레이어 번호·해상도·파일명 정보를 담은 annotation.json
- 이미지 목록과 초기 train/validation 분할을 담은 dataset.json

가려진 부분을 복원하지 않고 화면에 보이는 영역을 정답으로 지정하세요. 조명·주름은 같은 영역으로 묶는 등 일관된 기준이 중요합니다. 겹치는 마스크는 개별 마스크로 유지됩니다. 숨긴 레이어도 정답 데이터에 포함되므로 불필요한 레이어는 삭제하세요.

**이 버전은 학습 데이터를 수집하고 내보내는 단계입니다. 모델을 실제로 추가 학습하는 기능은 포함하지 않습니다.** 충분한 정답과 GPU 환경을 확인한 뒤 SAM 계열의 학습 파이프라인을 연결해야 합니다. 기본 분할은 임시 분할이므로 비슷하거나 중복된 이미지는 같은 그룹으로 묶고 별도 검증 세트를 검토해야 합니다.

## 제한과 검증

- 이미지당 최대 500만 픽셀, 최대 30 레이어. 이미지 선택 시 원본 한 장을 메모리에 읽습니다.
- 첫 분석은 로컬 CPU에서 진행되어 잠시 걸릴 수 있습니다. 아주 얇은 경계는 수동 보정이 필요합니다.
- 폴더 이미지가 바뀌면 위치 스캔을 눌러 목록을 갱신합니다.
- 저장한 마스크 바깥의 디코딩된 RGBA 픽셀은 보존합니다. PNG 원본 파일 바이트나 메타데이터 일치를 의미하지 않습니다.
- 300장 목록, 로컬 WASM 모델 추론, 영역 외 픽셀 보존, 이미지 이동과 작업 복원, 확정 마스크 내보내기, PNG 일괄 내보내기를 자동 테스트했습니다.
- 테스트 실행 환경의 Chromium 프로세스 제약 때문에 개발용 테스트에서만 샌드박스 실행 옵션을 조정했습니다. 설치 배포본은 Electron 렌더러 샌드박스를 유지합니다.

## 개발

Electron 44.3.0 / Transformers.js 3.5.0 / Xenova slimsam-77-uniform fp32.

소스 실행: Electron으로 이 디렉터리를 실행합니다. `main.cjs`는 선택된 폴더와 작업 저장을 관리하고, `ui/segment.worker.mjs`는 포함된 ONNX 모델을 WASM으로 실행합니다. `ui/core.mjs`는 마스크 색상 합성입니다.

공식 자료: https://www.electronjs.org/ · https://huggingface.co/Xenova/slimsam-77-uniform · https://github.com/huggingface/transformers.js · https://github.com/facebookresearch/sam2/tree/main/training



## 0.6.0 사용 안내

폴더를 열고 **일괄 분석 준비**를 누르면 마스크를 생성하지 않고 AI 분석에 필요한 이미지 정보를 디스크에 저장합니다. 다음 선택 때 재사용하며 앱을 다시 실행해도 유지됩니다. 준비 중에는 편집을 잠그며 **중지**는 현재 이미지 처리가 끝난 뒤 반영됩니다.

폴더의 파일을 바꾸거나 추가·삭제한 뒤 **위치 스캔**을 누르세요. 같은 파일명을 유지해도 이미지 내용이 달라졌으면 이전 마스크와 캐시를 사용하지 않습니다. 자동 실시간 감시 방식은 아닙니다.

**스킵 · 원본 저장**을 누른 이미지는 **작업 결과 일괄 저장**의 최종 폴더에 원래 확장자와 내용으로 복사됩니다. 학습 마스크 및 베타 ZIP에는 들어가지 않습니다. 스킵 해제 또는 편집으로 작업을 재개할 수 있습니다.

**앵커로 부위 다시 인식**은 현재 레이어의 포함·제외 클릭을 AI에 다시 전달합니다. **Ctrl+클릭**으로 앵커를 지운 뒤 이 버튼을 누르면 마스크를 갱신합니다. **Ctrl+Z**는 최근 편집을 되돌립니다. 텍스트 입력 중에는 해당 입력의 일반 되돌리기가 적용됩니다.

선택한 영역 경계의 안쪽 픽셀은 항상 부드럽게 혼합합니다. 영역 밖 원본 픽셀과 학습용 이진 마스크는 바꾸지 않습니다.

베타 제출은 검토·동의한 이미지와 마스크를 로컬 ZIP으로 만듭니다. 현재 버전은 Cloudflare R2에 자동 업로드하지 않습니다.


색상은 흰색(255,255,255)과 검정(0,0,0)만 선택할 수 있습니다. 기존의 다른 색상 레이어는 열 때 흰색으로 표시합니다. 불투명도와 경계 안티앨리어싱은 유지됩니다.

## 소스에서 빌드

Node.js와 npm을 설치한 Windows에서 `npm install` 후 `npm run dist:win`을 실행하세요. 모델 파일은 빌드 시 내려받고 SHA-256을 검증합니다. 배포 설치본에는 모델을 포함하므로 이용자는 오프라인으로 분석할 수 있습니다. 소스 저장소에는 사용자 이미지, 작업 데이터, 인증 키를 포함하지 않습니다.
